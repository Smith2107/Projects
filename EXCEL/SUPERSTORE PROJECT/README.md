## Project Overview

This project analyses superstore sales data using Microsoft excel.

the dashboard help understand sales performance, profit,customer behaviour,product categories,region and business trends.

## Tools used

- Microsoft excel
- pivot tables
- pivot charts
- slicers
- excel formulas
- data cleaning

- ## key business questions

- which reasons generates the highest sales?
- which product category generates the highest profit?
- which product perform well?
- which customer segment contribute the most to sales?
- how do sales change over time?

- ## dashboard features

- sales analysis
- profit analysis
- category-wise analysis
- region-wise analysis
- customer segment analysis
- interactive filters and slicers
